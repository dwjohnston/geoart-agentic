# Feature Brief: Render module nodes in the graph view

Source: GitHub issue #141

## Summary
`GraphView.tsx` currently has no handling for module nodes at all — only base node types are rendered. Module nodes should appear in the graph visualization.

## Notes
- Related to (closed) #23, which added the static graph visualisation view but predates modules being included.

Part of the UX polish pass (see project/offline_instructions.md).
